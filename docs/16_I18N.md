# 16 — INTERNATIONALIZATION (I18N) & RTL SPECIFICATION

**Project:** Abdulghani Al-Shibami — Autonomous Personal Portfolio Engineering System  
**Locales:** English (`en`, Default, LTR) | Arabic (`ar`, Secondary, RTL)  

---

## 1. Bilingual Architecture Principles
1. **Zero UI Duplication:** UI component JSX is never cloned for different languages. Layouts adapt dynamically based on locale context and CSS logical properties.
2. **Deep Typography Integration:**
   - English: `Playfair Display` (Editorial Titles & Headings) + `Geist` (Body & Navigation) + `JetBrains Mono` (Technical kickers & code metadata).
   - Arabic: `Noto Kufi Arabic` (Display, Headings, and Body) with balanced line-heights tailored for Arabic script ascenders/descenders.
3. **Strict Bi-directional Parity:** Every label, placeholder, navigation item, case study, and project summary has a complete verified translation located in `lib/i18n/dictionaries.ts`.
4. **Dynamic Pathname Preserving:** Language switcher switches between `/en/...` and `/ar/...` while preserving route path, query params, and state.

---

## 2. RTL Layout Adaptation Rules

```css
/* Core Logical Property Usage Guidelines */

/* INSTEAD OF: margin-left: 1rem; */
margin-inline-start: 1rem;

/* INSTEAD OF: padding-right: 1.5rem; */
padding-inline-end: 1.5rem;

/* INSTEAD OF: left: 0; */
inset-inline-start: 0;

/* INSTEAD OF: border-left: 2px solid gold; */
border-inline-start: 2px solid var(--border-gold);
```

- **Icon Directionality:** Directional navigation arrows (e.g. `ArrowRight`, `ChevronRight`) must mirror automatically in RTL (`scale-x-[-1]` or contextual icon swapping) so the user is guided naturally forward in reading direction.
- **Form Alignments:** Labels and inputs align to the right in Arabic without breaking floating action buttons.
