## 1. Bilingual Architecture Principles
1. **Zero UI Duplication:** UI component JSX is never cloned for different languages. Layouts adapt dynamically based on locale context and CSS logical properties.
2. **Deep Typography Integration:**
   - English: `Geist` (Headings & Body) + `JetBrains Mono` (Technical kickers & code metadata).
   - Arabic: `Noto Kufi Arabic` (Display, Headings, and Body) with balanced line-heights (1.75x) tailored for Arabic script ascenders/descenders.
3. **Strict Bi-directional Parity:** Every label, placeholder, navigation item, case study, and project summary has a complete verified translation located in `lib/i18n/dictionaries.ts`.
4. **Dynamic Pathname Preserving:** Language switcher switches between `/en/...` and `/ar/...` while preserving route path, query params, and state.

---

## 2. RTL Layout Adaptation Rules

```css
/* Core Logical Property Usage Guidelines */

/* INSTEAD OF: margin-left: 1rem; */
margin-inline-start: 1rem;

/* INSTEAD OF: padding-right: 1.5rem; */
padding-inline-end: 1.5rem;

/* INSTEAD OF: left: 0; */
inset-inline-start: 0;

/* INSTEAD OF: border-left: 2px solid neon-mint; */
border-inline-start: 2px solid var(--border-neon);
```

- **Icon Directionality:** Directional navigation chevrons mirror automatically in RTL (`scale-x-[-1]` or contextual icon swapping) so the user is guided naturally forward in reading direction.
- **Traffic Light Controls:** Preserved in native OS order (`Red - Yellow - Green`) across LTR and RTL to maintain realistic workstation authenticity.
- **Form Alignments:** Labels and inputs align to the right in Arabic without breaking floating action buttons.

## 3. Localization Dictionary Structure (`lib/i18n/dictionaries.ts`)

The project uses a unified dictionary interface (`Dictionary`) covering:
- `meta`: Localized document titles and OpenGraph descriptions.
- `nav`: Navigation labels, aria labels, and brand identity.
- `hero`: Greetings, editorial titles, verified coordinates placeholder, and action triggers.
- `telemetry`: HUD telemetry labels and invariant benchmark definitions.
- `featured`: Showcase section headers and verified status badges.
- `projectsPage`: Catalog titles, domain filters, status indicators, and bento grid strings.
- `caseStudy`: Architecture overview headings, topology labels, constraint summaries, and return buttons.
- `demos`: Interactive demo controls, sandbox disclosures, reset triggers, and fallback states.

---

## 4. Root HTML Synchronization & Deep Route Switching
- **Root Attributes:** Synchronized at both server render and client transition via `LocaleHtmlSync` and inline bootstrapping script.
- **English:** `<html lang="en" dir="ltr">`
- **Arabic:** `<html lang="ar" dir="rtl">`
- **Deep Route Preservation:** `LanguageSwitcher` replaces the `^/[locale]` segment ensuring nested routes (such as `/en/projects/campus-it-tracker/demo` ↔ `/ar/projects/campus-it-tracker/demo`) preserve state, project slug, and sub-paths.
