## 1. Skill Execution Protocol
The 19 engineering skills specified in `SKILLS.md` represent codified procedures that any engineering agent must execute when addressing specific domains.

### Invocation Rule
When working on a specific task:
1. Identify the matching skill from `SKILLS.md` (e.g., `interactive-demos`, `database-design`, `accessibility`).
2. Load and obey the documented inputs, outputs, validation rules, and anti-patterns.
3. Validate against the skill's specific Definition of Done prior to marking the task complete.
