# التصاميم التخيلية الحصرية — منصة المهندس عبدالغني الشبامي

> **الرؤية العامة:** تصميم تقني استثنائي وفاخر، يحول الموقع إلى منصة تحكم وهندسة برمجية متقدمة، حيث تُعرض مشاريع الديمو كأنها **تطبيقات حقيقية تعمل مباشرة داخل نظام تشغيل حاسوبك (Live Workstation Sandbox)**.

## 1. الواجهة الرئيسية وغرفة التحكم البرمجية (Hero Command Center)

تصميم فضائي - تقني فخم بلون الزمرد النيوني الفسفوري (`#00FF9D`) والأسود الكربوني العميق، يظهر هوية المهندس عبدالغني كقائد لأنظمة الذكاء الاصطناعي وهندسة البرمجيات مع مؤشرات تيليمتري حية، كونسول تشغيل، وربط بصري فريد.

## 3. محاكي سطح المكتب الحقيقي للمشروع (Desktop OS Workstation Sandbox)

تجسيد حرفي لطلبك بأن يبدو الديمو **تماماً كأنه تطبيق حقيقي يعمل داخل جهاز الكمبيوتر**:
- إطار نافذة نظام التشغيل الاحترافي مع أزرار التحكم الثلاثية (Traffic Light Controls: أحمر، أصفر، أخضر).
- شريط العنوان التقني: `MetaAlgorithm Lab v2.4 — Live Native Execution Sandbox`.
- ترمينال مدمج يبث سجلات التنفيذ واستهلاك الذاكرة الحقيقي (`Sort time: 3.14ms`, `MEM Usage: 14.8MB`).
- محرك بصري تفاعلي للخوارزميات ومسارات $A^*$ مع فاحص بيانات حية (Live Database & Variables Inspector).
- مؤشرات استهلاك العتاد المباشرة (CPU 18%, MEM 23%, NET 1.2MB/s).

## 4. شبكة استعراض المشاريع الخمسة الحية (Live Projects Showcase Grid)

استعراض معماري متكامل لكافة مشاريعك الخمسة الأصيلة:
1. **Campus IT Tracker**: نظام إدارة أصول الجامعة مع خريطة تفاعلية للمباني والدعم الفني.
2. **MetaAlgorithm Lab**: مختبر الخوارزميات وتحليل الكفاءة ومقارنة الأداء في الوقت الفعلي.
3. **Cafena Coffee Suite**: نظام إدارة الكافيه والمبيعات السحابية ونقاط البيع POS.
4. **NovaTech Cloud**: منصة مراقبة البنية التحتية وإنترنت الأشياء والشبكات.
5. **GP Graduation Platform**: بيئة متابعة وإدارة مشاريع التخرج الأكاديمية والتقييم.

كل بطاقة مشروع مصممة كشاشة كمبيوتر حية برابط بيانات متوهج وزر تشغيل مباشر للديمو المحاكي (`Launch Workstation Demo`).
